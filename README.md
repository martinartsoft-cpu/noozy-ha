# Noozy pro Home Assistant

Repozitář aplikací (doplňků) pro Home Assistant: **Noozy Watcher** - hlídá 3D tiskárny 24/7 a předává tisky do
[Noozy](https://noozy.cz) na PC. Návod: [noozy_watcher/DOCS.md](noozy_watcher/DOCS.md).

Home Assistant app repository: **Noozy Watcher** - watches your 3D printers 24/7 and hands prints over to Noozy on the PC.

**Přidání do HA / Add to HA:** Nastavení → Aplikace → Obchod s aplikacemi → ⋮ → Repozitáře → adresa tohoto repozitáře.

Blueprint „málo filamentu před tiskem": [blueprints/automation/noozy/noozy_filament_check.yaml](blueprints/automation/noozy/noozy_filament_check.yaml)
